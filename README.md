# 🎲 Eterium

**Eterium** é um projeto acadêmico desenvolvido na UNIP, utilizando linguagens de marcação e programação web.

O objetivo principal do projeto foi apresentar o universo de um RPG por meio de uma interface moderna, intuitiva e visualmente envolvente.

---

## 🎯 Objetivo

Criar uma experiência digital que:

- 📖 Apresente o conceito e a narrativa do RPG  
- 🎨 Valorize a identidade visual do projeto  
- 🧭 Ofereça navegação clara e intuitiva  
- 💡 Aplique princípios de UI (User Interface) e UX (User Experience)

---

## 🛠 Tecnologias Utilizadas

- HTML  
- CSS  
- JavaScript  
---

## 🚀 Proposta

O projeto buscou unir design e funcionalidade, transformando a apresentação do RPG em uma experiência imersiva, organizada e acessível ao usuário.

---

> Mais do que um site, Eterium representa a aplicação prática de conceitos de desenvolvimento web e design centrado no usuário.
